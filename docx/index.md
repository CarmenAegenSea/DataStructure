# 数据结构实验项目文档索引

本项目是一个基于 C 语言实现的数据结构学习与实验仓库，主要包括常见线性结构与非线性结构的定义、实现和测试。

---

## 1. 项目概览

该项目的核心代码集中在 [include](../include) 目录中，主要包含以下内容：

- 基础类型定义：Def.h
- 顺序表：List.h / List.cpp
- 单链表：LinkList.h / LinkedList.cpp
- 栈：Stack.h / Stack.cpp
- 队列：Queue.h / Queue.cpp
- 串：SqString.h / SqString.cpp
- 广义表：GList.h / GLinkList.h / GLinkList.cpp

对应的源码示例与实验程序位于 [src](../src) 目录中，测试和生成结果则保存在 [build](../build) 中。

---

## 2. 文档导航

- [include.md](include.md)：说明项目中所有头文件的定义、结构体、接口和使用场景。
- 本文档：项目总览与导航入口。

---

## 3. 结构学习顺序

建议按以下顺序熟悉本项目：

1. 基础定义与状态码：Def.h
2. 线性表：List.h、LinkList.h
3. 栈与队列：Stack.h、Queue.h
4. 字符串：SqString.h
5. 广义表：GList.h、GLinkList.h

这种顺序与数据结构课程中的学习路径一致，便于从基础抽象到复杂结构逐步理解。

---

## 4. 代码组织说明

项目结构大致如下：

- [include](../include)：数据结构抽象接口与类型声明
- [src](../src)：各类数据结构的使用示例和实验代码
- [build](../build)：编译后的程序文件或测试输出
- [docx](../docx)：文档说明与说明书

---

## 5. 学习建议

- 先看头文件定义，理解结构体设计和函数接口。
- 再结合实现文件，确认数据结构的增删查改逻辑。
- 最后通过 src 中的实验代码进行验证和调试。
- 对照 ADT 的特点理解“顺序存储”和“链式存储”的差异。

---

## 6. 总结

该项目覆盖了数据结构中最常见的几种抽象数据类型，并以头文件为核心，结构清晰、便于学习和扩展。若要快速入门，推荐优先阅读 [include.md](include.md) 与各头文件定义，再结合源码理解具体实现。
